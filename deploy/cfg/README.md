# Правка конфигов аудио-эффектов

Скрипты `deploy2.sh` и `refix.sh` патчат конфиги устройства сами (через `sed`), поэтому готовые
копии в репозитории не нужны. Здесь описано, что именно добавляется в
`/vendor/etc/audio_effects_config.xml` и `/odm/etc/audio_effects_config.xml`.

В секцию `<libraries>` добавляется библиотека моста:

```xml
<library name="dap_shim" path="libdolbyaidlshim.so"/>
```

В секцию `<effects>` добавляется сам эффект. Атрибут `type` обязателен: без него парсер эффектов
молча пропускает запись, потому что ищет тип в таблице известных типов.

```xml
<effect name="dap_mod" library="dap_shim"
        uuid="9d4921da-8225-4f29-aefa-39537a04bcaa"
        type="e119e520-7dfc-4a15-b1fa-234a0939f082"/>
```

`uuid` здесь публичный (из конфигов существующих модов), но при создании эффекта мост подменяет его
на UUID из самой библиотеки Dolby, иначе движок отвечает `ENOENT` (см. `docs/TECHNICAL.md`).

Дополнительно: правка файла-источника не видна через уже смонтированный bind. После изменения
конфига нужно перемонтировать его (`umount` + `mount -o bind`), иначе парсер продолжит видеть старую
версию файла.
